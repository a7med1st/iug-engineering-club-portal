# بوابة النادي الهندسي للطلاب – IUG

مشروع Full‑Stack جاهز كبداية عملية للموقع المطلوب، باستخدام **Next.js + Prisma + PostgreSQL + Docker**.

## ما تم تنفيذه
- تسجيل دخول بطريقتين فقط: **طالب** و **عضو**.
- الطالب يستطيع إنشاء حساب بأي بريد إلكتروني صالح (Gmail أو أي نطاق آخر).
- حساب الطالب لا يمكنه الدخول من بوابة الأعضاء.
- العضو لا يستطيع إنشاء حساب لنفسه؛ **الإدارة فقط** تنشئ حسابات الأعضاء من لوحة الإدارة.
- لوحة الإدارة محمية ولا تظهر للطلاب أو الأعضاء العاديين.
- صفحات: الرئيسية، الأنشطة، الأقسام، المناديب/الهيكلية، من نحن.
- الأنشطة: متاحة/جارية افتراضيًا + تبويب للأنشطة الفائتة، وتصنيف عام أو حسب القسم، مع الموعد/المكان/السعة/رابط الفورم.
- دليل الأقسام: الحقول المطلوبة كلها موجودة لكنها **فارغة افتراضيًا** حتى يتم إدخال محتوى معتمد لاحقًا من الإدارة.
- لوحة الإدارة: إضافة نشاط، حذف نشاط، إنشاء حساب عضو، تحرير أدلة الأقسام، إضافة عناصر الهيكلية.
- Intro animation: الشعار في المنتصف ثم انقسام الشاشة قطريًا بزاوية 45°.
- تم دمج كل صور الحرم وصور الأقسام المرفقة في المشروع.
- خطوط الأقسام حسب المطلوب: Orbitron / Space Grotesk / Rajdhani / Exo 2، مع Manrope وSora للإنجليزية وAmiri Quran وAlexandria للعربية.

> ملاحظة مهمة: لم يتم إرفاق شعار النادي الرسمي ضمن الملفات الحالية، لذلك وضعت `public/images/club-logo.svg` كـ **Placeholder** واضح. استبدله بالشعار الرسمي بنفس الاسم أو عدّل المسار في `Header.tsx` و`IntroGate.tsx`.

## التشغيل على Windows
1. ثبّت Node.js 20+ وDocker Desktop.
2. انسخ `.env.example` إلى `.env` ثم غيّر `SESSION_SECRET` وبيانات الأدمن.
3. شغّل Docker Desktop وتأكد أن المحرك يعمل.
4. من PowerShell داخل مجلد المشروع:

```powershell
npm.cmd install
docker compose up -d
npm.cmd run db:generate
npm.cmd run db:migrate -- --name init
npm.cmd run db:seed
npm.cmd run dev
```

ثم افتح `http://localhost:3000`.

## حساب الأدمن الأول
يتم إنشاؤه من متغيرات البيئة:
- `SEED_ADMIN_EMAIL`
- `SEED_ADMIN_PASSWORD`

الأدمن يسجّل الدخول من تبويب **عضو**؛ بعدها يتم تحويله تلقائيًا إلى `/admin`.

## ملاحظات قبل الإنتاج
- استخدم `SESSION_SECRET` قويًا وعشوائيًا.
- لا توجد بيانات أدمن افتراضية داخل الكود؛ اضبط `SEED_ADMIN_EMAIL` و`SEED_ADMIN_PASSWORD` قبل تشغيل الـseed إذا أردت إنشاء حساب أدمن.
- استبدل روابط Google Forms التجريبية بروابط التسجيل الحقيقية.
- يفضل إضافة rate limiting وCSRF protection وemail verification قبل الإطلاق العام.
